## ✨ About

PABITRA-BOT is a customizable WhatsApp MD bot built with the Baileys library. It features a modular command system and useful tools for managing your bot.

## 🚀 Features

- Modular command system
- Custom command prefix
- Media and utility commands
- Owner management tools
- WhatsApp session management
- Custom bot name and profile image
- Termux and compatible hosting support
