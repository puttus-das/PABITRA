PABITRA-BOT is a WhatsApp MD bot built using the Baileys library.

It is designed to be lightweight, customizable, and easy to manage. You can personalize the bot name, image, prefix, and supported features according to your needs.

---

## ✨ Features

- **Open Source** — customize the code while respecting the original license.
- **Easy Customization** — configure the bot name, prefix, image, and other supported settings.
- **Modular Commands** — commands are organized in the `commands/` folder.
- **Session Management** — manage WhatsApp sessions using the configuration supported by your project.
- **Owner Utilities** — use available owner commands to manage the bot.
- **Termux Support** — run locally on a compatible Android environment.

## 3. Local Setup

### Install the requirements

```bash
pkg update
pkg install nodejs git
```

### Clone your repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_REPOSITORY_FOLDER
```

### Install dependencies

```bash
npm install
```

### Configure the bot

Open `config.js` and configure the settings supported by your version.

If your project uses a `sessionID` setting, follow the format expected by the actual source code.

### Start the bot

```bash
node index.js
```

Follow the terminal instructions to connect WhatsApp.

---

## 4. Run on Termux

```bash
cd ~/PABITRA-BOT/Rahi-main
npm install
node index.js
```

If your project is stored in another directory, change the path accordingly.
