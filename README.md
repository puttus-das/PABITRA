✨ About PABITRA-BOT

PABITRA-BOT is a WhatsApp MD bot built with the Baileys library. It is designed to be lightweight, customizable, and easy to manage.

Customize your bot name, profile image, command prefix, and features according to your needs.

🚀 Features

- Modular Commands — Commands organized inside the "commands/" folder.
- Custom Prefix — Configure the command prefix.
- Media Tools — Support for media-related commands.
- Owner Commands — Utilities for bot management.
- Session Management — Configure your WhatsApp session.
- Custom Branding — Personalize your bot's name and profile image.
- Self-Hosting — Run on Termux, a VPS, or a compatible hosting platform.

---

📥 Installation

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_REPOSITORY_FOLDER

Replace the example values with your actual GitHub repository URL and folder name.

2. Install Dependencies

npm install

3. Configure the Bot

Open "config.js" and configure the settings supported by your version of PABITRA-BOT.

Keep session strings, API keys, and other secrets private. Do not upload them to a public repository.

4. Start the Bot

node index.js

Follow the terminal instructions to connect WhatsApp, if required by your configuration.

---

📱 Run on Termux

pkg update && pkg upgrade
pkg install nodejs git
cd ~/PABITRA-BOT/Rahi-main
npm install
node index.js

Use the correct project path if your folder is named differently.
